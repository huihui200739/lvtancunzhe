# 证据范围

本目录提供适合团队分享的构建元数据和原生检查摘要。完整原始日志、RDB副本及历史录屏留在维护者本机，不进入仓库。

- `clean-clone.json`：干净克隆的源码提交与验证结果，不含本机临时目录。
- `packages.json`：本次两个release包的bundle、版本、大小和SHA-256。
- `native-20261027.json`：原生检查范围、设备、日期、截图及未覆盖项。
- `checks-20261027.txt`：服务回归与release构建结果摘录；原生验证不由该文本替代。

说明：摘要可供成员定位，复查时应结合GitHub Actions、可复现命令和自己实际运行的结果，不把摘要文字当成全部原始证据。
