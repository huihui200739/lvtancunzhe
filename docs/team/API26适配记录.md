# API 26 适配记录

状态：进行中，API 26 release 编译及模拟器基础流程通过，其余原生运行验证待完成。当前团队试用版本仍以 API 24 验收结果为准。

## 配置与边界

- `build-profile.json5` 保留原有 `default`（API 24）配置，另设实验性 `api26` product，编译与目标 SDK 使用 `26.0.0`，最低兼容版本保持 12。工程模型版本升级至 6.0.0。
- API 12 是配置的最低兼容版本，不代表已经在所有 API 12 及以上设备验证。API 26 的编译、安装与实际运行亦须单独验证。
- `build.sh` 和 `scripts/setup-sdk.sh` 默认仍使用 API 24；可用 `GREEN_BUILD_PRODUCT=api26` 选择实验配置，并通过 `DEVECO_HOME` 和 `OPENHARMONY_SDK_HOME` 指向自己的新版工具链和 SDK 路径。脚本不会替使用者接受 SDK 许可。
- `local.properties` 内的 `sdk.dir` 会覆盖环境变量中指定的 SDK 位置；选择 API 26 时应确保它指向包含 `26.0.0` 目录的 SDK 根目录，不能假设环境变量会覆盖它。
- 不更换包名、不清空或迁移维护者现有开发库。原生验收使用独立 QA 包及测试数据；正式核算继续排除未核验因子。

- 2026-10-28，`npm test` 的 59 项隔离服务回归通过；它不覆盖原生界面和 API 26 运行行为。
- 2026-10-28，下载的 DevEco Studio 26.0.0.851 安装包 SHA-256 与华为官网下载页面一致；随附 OpenHarmony SDK 元数据为 API 26、26.0.0.105。首次构建使用了错误的 SDK 根目录，导致工具链尝试下载 SDK 并报告许可未接受；修正路径后无需重新接受许可，API 26 正式 HAP 编译成功，产物未签名。工程模型升级后 API 24 的正式 HAP 也重新编译成功。
