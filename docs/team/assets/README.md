# 界面素材

供团队PPT和说明使用。截图来自1.1.3 release模式的独立QA包，展示模拟器内的测试/演示数据，不代表真实减排成果或真人试用结论。

本轮截图日期：2026-10-27；环境：Pura 90手机模拟器、API24、1320×2856。`plan.jpeg`若显示10月18日起的计划，是保留的历史计划示例；不得改注为10月27日新生成的计划。

| 文件 | 用途 |
|---|---|
| ledger.jpeg | 首页与局部行为累计 |
| plan.jpeg | 目标、单位紧凑排版、保存的计划上下文 |
| dashboard.jpeg | 默认近期范围；若为空，表示该范围无记录，不是总账被清空 |
| dashboard-populated.jpeg | 历史范围10月1—27日的统计示例，不能标成当周成果 |
| charts.jpeg | 历史范围图表，数值为QA演示数据 |
| knowledge.jpeg | 离线科普与分类 |
| profile.jpeg | 积分和虚拟成就 |
| voucher.jpeg | 记录、情景与冻结凭证，超出首屏部分可由成员按指南重拍 |

需要展示完整业务流程或当前日期的新计划时，请成员使用自己的QA数据重新录制。截图只供界面展示，不能替代未完成的真实人员试用。
